# haEWAS Figure Reproduction

This repository provides the figure reproduction package for the heterogeneity-adjusted epigenome-wide association study (haEWAS). It contains the executable notebook, source data tables, and exported figure panels used to reproduce the main and supplementary figure results.

The central analysis and plotting workflow is implemented in:

```text
Reproduction_figures.ipynb
```

All code-generated figure panels are organized by figure-specific directories, each containing source data and exported figure files. Conceptual schematic figures created with BioRender are documented here but are not generated programmatically by the notebook.

## Repository Structure

```text
.
├── Phenotype_descriptions.xlsx   # Summary and brief descriptions of the 46 human phenotypes analysed by EWAS and haEWAS.
├── Reproduction_figures.ipynb    # Main notebook containing all executable reproduction code
├── arial.ttf                     # Font file used for consistent figure rendering
├── Fig2/                         # Figure 2 source data and exported panels
├── Fig3/                         # Figure 3 source data and exported panels
├── Fig4/                         # Figure 4 source data and exported panels
├── Fig5/                         # Figure 5 source data and exported panels
├── Fig6/                         # Figure 6 source data and exported panels
├── FigS1/                        # Supplementary Figure 1 source data and exported panels
├── FigS2/                        # Supplementary Figure 2 source data and exported panels
├── FigS3/                        # Supplementary Figure 3 source data and exported panels
├── FigS4/                        # Supplementary Figure 4 source data and exported panels
├── FigS6/                        # Supplementary Figure 6 source data and exported panels
└── FigS7/                        # Supplementary Figure 7 source data and exported panels
```

For each code-generated figure directory:

```text
Fig*/source_data/    # Panel-level source data tables
Fig*/figures/        # Reproduced panels in PDF, SVG, and/or PNG format
```

Figure 1 and Supplementary Figure 5 are conceptual BioRender schematics and therefore do not have code-generated source-data directories in this repository.

Python 3.8.16

```text
numpy

```

Package imports and any figure-specific setup are included in `Reproduction_figures.ipynb`. For best visual consistency, keep `arial.ttf` in the repository root when running the notebook.

## How to Reproduce the Figures

1. Clone or download this repository.
2. Open `Reproduction_figures.ipynb` in Jupyter Notebook, JupyterLab, VS Code, or another compatible notebook environment.
3. Use a Python environment with the required scientific and plotting packages installed.
4. Run the notebook cells in order, or run the figure-specific sections corresponding to the panel of interest.
5. Generated panels are written to the corresponding `Fig*/figures/` directories.
6. Panel-level source data are available in the corresponding `Fig*/source_data/` directories.

The notebook is intended to reproduce code-generated figure panels from the source data supplied in this repository. BioRender schematics are not regenerated by code.

## Figure Reproduction Guide

### Figure 1 Reproduction

Figure 1 is a conceptual schematic created with BioRender. It illustrates the rationale and workflow of heterogeneity-adjusted EWAS (haEWAS), including methylation average-to-heterogeneity conversion (A2H), population methylation data processing, phenotype association analysis, and expected downstream applications.

This conceptual figure was created manually and is not generated by the analysis notebook.

### Figure 2 Reproduction

Figure 2 summarizes the discovery landscape of phenotype-associated methylation loci identified by conventional EWAS and heterogeneity-adjusted EWAS (haEWAS).

Fig. 2a compares association significance between EWAS and haEWAS across significant loci. Each point represents one locus, with EWAS -log10(P) on the x-axis and haEWAS -log10(P) on the y-axis. Points are grouped as EWAS-specific, haEWAS-specific, or common signals, and the marginal density plots show the significance distributions for each signal class.

Fig. 2b compares the number of EWAS-specific and haEWAS-specific loci across the 46 curated phenotypes. Each point represents one phenotype, colored by trait category and shaped by trait type. The x-axis shows EWAS-specific loci and the y-axis shows haEWAS-specific loci, both on a log10(n + 1) scale. Selected phenotypes are labelled to highlight traits with strong haEWAS contribution and substantial total discovery.

Fig. 2c summarizes the relative gain of haEWAS-specific loci over EWAS-specific loci across trait categories. The gain score is defined as log2[(haEWAS + 1)/(EWAS + 1)], where positive values indicate haEWAS-favored discovery and negative values indicate EWAS-favored discovery. Each point represents one phenotype, and boxplots summarize the distribution of gain scores within each trait category.

Together, Figure 2 shows that haEWAS identifies a complementary set of phenotype-associated methylation loci and that the relative contribution of haEWAS varies across phenotypes and biological trait categories.

### Figure 3 Reproduction

Figure 3 evaluates haEWAS in breast cancer by comparing discovery overlap, genome-wide signal distribution, and out-of-cohort prediction performance between conventional EWAS and haEWAS.

Fig. 3a shows the overlap between significant EWAS loci and significant haEWAS loci in breast cancer. CpGs are grouped as EWAS-specific, haEWAS-specific, or common signals, with haEWAS defined as the union of CHALM and CAMDA significant CpGs.

Fig. 3b shows a signed Manhattan plot of breast cancer association signals across autosomes. The y-axis shows signed -log10(P), where the sign reflects the direction of the meta-analysis effect estimate. Significant CpGs are colored by discovery group: EWAS-specific, haEWAS-specific, or common.

Fig. 3c compares methylation risk score distributions between normal and breast cancer samples across held-out cohorts. Density curves are shown separately for EWAS and haEWAS scores, allowing visual comparison of disease-control separation within each cohort.

Fig. 3d compares Cohen's d effect sizes between EWAS and haEWAS methylation risk scores across paired held-out cohorts. Lines connect paired cohort-level estimates, showing whether haEWAS improves group separation relative to EWAS.

Fig. 3e-h show ROC curves for held-out breast cancer cohorts. Each panel compares EWAS and haEWAS prediction performance using the corresponding z-normalized methylation risk scores. AUC values summarize classification performance for each method in each cohort.

Together, Figure 3 demonstrates that haEWAS identifies breast cancer-associated methylation signals that complement conventional EWAS and can improve disease-control separation and prediction in held-out cohorts.

### Figure 4 Reproduction

Figure 4 characterizes the biological and regulatory relevance of haEWAS-associated loci in Braak stage analysis. The figure compares EWAS-specific, haEWAS-specific, and common loci using functional enrichment, genomic annotation enrichment, and eQTM analyses.

Fig. 4a shows GO biological process enrichment terms for EWAS-specific, common, and haEWAS-specific loci.

Fig. 4b shows enrichment of genomic locations and CpG island contexts across loci categories. Bars represent log2(odds ratio), with positive values indicating enrichment and negative values indicating depletion. Asterisks denote enrichment significance.

Fig. 4c summarizes significant eQTM pairs detected by EWAS and haEWAS. The Venn diagram compares EWAS-specific, common, and haEWAS-specific significant eQTM pairs, and the boxplot compares absolute eQTM effect sizes for common eQTM pairs between average methylation and methylation heterogeneity.

Fig. 4d highlights representative rescued eQTM pairs in selected biological pathways. Each row shows the change in eQTM significance from EWAS to haEWAS using -log10(FDR), with arrows indicating improved significance under haEWAS.

Together, Figure 4 shows that haEWAS-specific loci are enriched for biologically meaningful functional annotations and can reveal regulatory eQTM signals that are weaker or not significant under conventional EWAS.

### Figure 5 Reproduction

Figure 5 evaluates the cross-cancer relevance and prognostic utility of haEWAS-derived methylation heterogeneity signals.

Fig. 5a summarizes the number of EWAS-specific, common, and haEWAS-specific loci across TCGA cancer projects. The heatmap shows the number of loci in each discovery class for each project, highlighting the broad contribution of haEWAS-specific signals across cancer types.

Fig. 5b compares survival prediction performance across different feature sets. The curves show median C-index values across increasing numbers of top-ranked loci, with interquartile ranges indicating variability across projects. The three models correspond to average methylation (m), methylation heterogeneity (hm), and the integrated model (m + hm).

Fig. 5c-e show representative Kaplan-Meier survival analyses for selected prognostic methylation markers in three cancer cohorts. For each cancer project, patients are stratified into high- and low-risk groups using a median split. The two subpanels compare survival separation based on average methylation (m) and methylation heterogeneity (hm), respectively.

Together, Figure 5 shows that haEWAS-derived heterogeneity signals are widespread across cancer types and can provide prognostic information that complements conventional average methylation signals.

### Figure 6 Reproduction

Figure 6 defines cell-type-specific differential methylation patterns in liver cancer and highlights the biological relevance of haEWAS-specific DMCTs.

Fig. 6a summarizes hypermethylated and hypomethylated DMCTs across major liver cell types. For each cell type, DMCTs are partitioned into haEWAS-specific, common, and EWAS-specific loci. Positive bars denote hypermethylated DMCTs and negative bars denote hypomethylated DMCTs.

Fig. 6b quantifies the overlap of haEWAS-specific DMCTs across liver cell types with an UpSet plot. Each event is defined by a CpG together with its methylation direction. The top bars indicate intersection sizes, the membership matrix shows the contributing cell types, and the right bars show the total number of haEWAS-specific DMCTs in each cell type.

Fig. 6c-d display cell-type-resolved t-statistic landscapes for hepatocytes and cholangiocytes. Each point represents a CpG, plotted by t-statistic and -log10(FDR), and colored by loci category: haEWAS-specific, common, EWAS-specific, or background. Rug annotations summarize the strongest ranked CpGs by category and direction, and selected gene labels highlight the most prominent signals.

Fig. 6e-f present GO biological process enrichment of DMC-associated genes in hepatocytes and cholangiocytes. Heatmap intensity represents capped -log10(FDR) values, whereas white cells indicate non-significant or unavailable enrichment. Columns compare haEWAS-specific, common, and EWAS-specific loci categories.

Together, Figure 6 shows that haEWAS resolves liver cancer methylation changes at cell-type resolution and reveals biologically coherent DMCT-associated pathways that are less apparent from conventional EWAS alone.

### Supplementary Figure 1 Reproduction

Supplementary Figure 1 evaluates external array-WGBS validation of methylation heterogeneity reconstruction.

Fig. S1a-b show paired array-WGBS validation for hm(CAMDA) and hm(CHALM), respectively. Each hexbin summarizes the density of displayed CpG-sample observations, comparing WGBS-derived heterogeneity values with array-derived predicted heterogeneity values. Agreement is quantified by RMSE and Pearson correlation, and N denotes the number of displayed CpG sites used for visualization.

Together, Supplementary Figure 1 shows that the A2H transformation accurately recapitulates methylation heterogeneity estimates from WGBS in external paired array-WGBS validation data.

### Supplementary Figure 2 Reproduction

Supplementary Figure 2 evaluates the distributional properties of average methylation and methylation heterogeneity metrics across representative disease-tissue settings.

Fig. S2a-c show the value distributions of m, hm(CAMDA), and hm(CHALM) across selected disease cohorts. The filled density curve shows the raw metric distribution on the 0-1 scale, while the dashed curve shows the corresponding M-value distribution after logit transformation. These panels illustrate how average methylation and heterogeneity-derived metrics differ in scale and distributional shape.

Fig. S2d compares cohort-level KS statistics across m, hm(CAMDA), and hm(CHALM) before and after M-value transformation. Boxplots summarize the distribution of KS statistics across cohort comparisons for schizophrenia, liver cancer, and medulloblastoma. Raw-scale metrics and M-value-transformed metrics are shown separately, and significance annotations indicate pairwise differences between methods.

Together, Supplementary Figure 2 shows that methylation heterogeneity measures exhibit distributional properties distinct from average methylation and that M-value transformation improves comparability for downstream association analyses.

### Supplementary Figure 3 Reproduction

Supplementary Figure 3 provides a phenotype-level overview of EWAS and haEWAS discovery results across 46 curated traits.

For each phenotype, stacked bars show the relative fraction of EWAS-specific, common, and haEWAS-specific loci. The adjacent dot plot shows the total number of significant loci, allowing both proportional and absolute discovery patterns to be compared.

Phenotypes are grouped by biological or clinical trait category, including cancer, neurological, cardiovascular, immune, metabolic, and other traits. Sample-size information is shown alongside each phenotype to indicate the scale of the underlying EWAS and haEWAS analyses.

Asterisks mark phenotypes in which the haEWAS-specific fraction exceeds the EWAS-specific fraction, highlighting traits where methylation heterogeneity contributes more strongly to locus discovery than conventional average methylation.

### Supplementary Figure 4 Reproduction

Supplementary Figure 4 evaluates the statistical calibration and biological annotation patterns of EWAS and haEWAS results in breast cancer.

Fig. S4a compares genomic inflation factors across individual breast cancer cohorts. Each point represents the inflation factor lambda for one cohort and one analysis method: EWAS, haEWAS(CAMDA), or haEWAS(CHALM). The vertical reference line marks lambda = 1, indicating the expected value under well-calibrated test statistics.

Fig. S4b shows QQ plots for the breast cancer meta-analysis. Expected and observed -log10(P) values are shown for EWAS, haEWAS(CAMDA), and haEWAS(CHALM), allowing direct comparison of genome-wide calibration and association signal enrichment.

Fig. S4c shows GO biological process enrichment for EWAS-specific, common, and haEWAS-specific loci. The x-axis shows -log10(P), point size indicates the number of differentially enriched genes, and colors indicate loci categories.

Fig. S4d summarizes genomic location enrichment across loci categories. Bars show log2(odds ratio) values for gene regions and CpG island contexts, with positive values indicating enrichment and negative values indicating depletion.

Together, Supplementary Figure 4 shows that haEWAS maintains acceptable statistical calibration while identifying breast cancer-associated loci with distinct functional and genomic annotation patterns.

### Supplementary Figure 5 Reproduction

Supplementary Figure 5 is a conceptual schematic created with BioRender. The figure illustrates the methylation risk score (MRS) prediction workflow and the leave-one-cohort-out (LOCO) validation strategy used for disease-status prediction. It summarizes how cohort-level training and held-out validation were organized to evaluate the predictive performance of EWAS- and haEWAS-derived methylation signatures.

This conceptual figure was created manually and is not generated by the analysis notebook.

### Supplementary Figure 6 Reproduction

Supplementary Figure 6 evaluates haEWAS performance in the Braak stage reproduction analysis by comparing overlap with previously reported EWAS loci, genome-wide signal distribution, statistical calibration, and cohort-level inflation factors.

Fig. S6a compares significant loci reported by the previous EWAS study with significant loci identified by haEWAS. The Venn diagram summarizes EWAS-specific, common, and haEWAS-specific loci, where haEWAS loci are defined as the union of significant loci identified by haEWAS(CAMDA) and haEWAS(CHALM).

Fig. S6b shows a signed Manhattan plot for Braak stage association signals across autosomes. Points represent CpGs, with signed -log10(P) indicating association strength and effect direction. Significant loci are colored as EWAS-specific, common, or haEWAS-specific.

Fig. S6c compares genomic inflation factors across single cohorts for EWAS, haEWAS(CAMDA), and haEWAS(CHALM). The vertical reference line marks lambda = 1, indicating the expected value under well-calibrated test statistics.

Fig. S6d shows QQ plots for the Braak stage meta-analysis. Expected and observed -log10(P) values are compared across EWAS, haEWAS(CAMDA), and haEWAS(CHALM), allowing assessment of statistical calibration and genome-wide signal enrichment.

Together, Supplementary Figure 6 shows that haEWAS recovers loci overlapping with previous EWAS findings while also identifying additional Braak-stage-associated methylation heterogeneity signals with interpretable genome-wide distribution and statistical calibration.

### Supplementary Figure 7 Reproduction

Supplementary Figure 7 compares survival prediction performance across TCGA cancer projects using methylation-risk models based on average methylation (m), methylation heterogeneity (hm), and the combined feature set (m + hm). Curves show C-index values across increasing numbers of top-ranked features, allowing the predictive contribution of heterogeneity-derived features to be evaluated across cancers.
